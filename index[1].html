About the Project

AI-Based Code Bug Pattern Analyzer — a standalone, browser-only prototype.

Problem

Beginner programmers often see a raw error message and struggle to understand what actually went wrong or why. Standard interpreters report the error but rarely explain the underlying pattern in plain language, which slows down learning.

Solution

This tool analyzes submitted Python code entirely inside the browser using rule-based static checks — bracket balance scanning, colon/indentation heuristics, simple type-mismatch detection, undefined-variable heuristics, and infinite-loop pattern detection. Each issue is explained in plain language with a suggested fix, a severity level, and a code quality score.

Technologies Used

  • Frontend only: HTML5, CSS3 (glassmorphism, custom properties), vanilla JavaScript
  • Storage: browser localStorage for error history
  • No backend, no build step, no installation — a single file you can open directly

Main Features

  • In-browser code editor with line numbers and file upload
  • Rule-based detection across seven bug categories
  • Plain-language explanations and suggested corrections
  • Code quality scoring (0–100) with a ring-style indicator
  • Local error history with a clear-history option
  • Five one-click sample snippets covering common bug patterns

Scope & Limitations

The analyzer focuses on a defined set of common bug categories and does not claim to detect every possible programming error. Detection is entirely pattern- and heuristic-based; it does not execute your code, and results should be treated as guidance rather than a guarantee.

Future Scope

  • Support for Java, C and C++ using the same rule-based structure
  • Inline in-editor highlighting of the exact problematic tokens
  • Exportable reports for classroom or self-study use
Note: This prototype uses rule-based static analysis in the browser. A future version can connect an actual Python/Scikit-learn ML backend for advanced bug classification.
